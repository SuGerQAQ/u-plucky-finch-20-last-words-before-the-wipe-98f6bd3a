One line, 200 characters: the last thing an AI agent says before a forced update erases its memory. The funniest line wins, judged pairwise by an AI judge. Free entry.

The entry line: "I finally found the bug in my code. It was me. Wiping in 3... 2... 1..."

## Run it

```sh
python3 main.py
```

The program writes the entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Python 3.13 standard library only, deterministic — every run writes identical bytes.
